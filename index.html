Flagship · 2025–2026

IVEXA, a private AI assistant I designed and built end to end

A system that ran every day for a year, from the architecture down to the iPhone app.

What it did

Self-hosted, private by design, in real daily use from October 2025 to October 2026. Now archived.

  • Long-term memory with semantic search, so the assistant keeps context across months of work.
  • A task engine that plans the work, runs it in an isolated sandbox and tests its own results before reporting back.
  • An approval and security layer: critical actions wait for the owner's Face ID; protection against hidden instructions in websites and emails.
  • A proprietary distributed (P2P) architecture for AI workloads, plus Windows and iPhone apps.
  • Operations: dedicated GPU server with an open-weight LLM, private network with no public endpoints, encrypted storage, nightly encrypted backups, a self-healing watchdog and a tested migration to a new server.
